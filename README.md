# Vinod R — Premium Portfolio

A responsive personal portfolio built with:
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Run locally
Open `index.html` in a browser.

For the best local development experience, use VS Code + Live Server.

## Before publishing
Replace/add:
- Exact education details
- Circlo GitHub repository URL
- Actual certificates
- Data-analysis certificate name and credential link
- Any future internships
- More project screenshots
- Resume PDF in `documents/`

## Publish with GitHub Pages
1. Create a repository (for example `portfolio`).
2. Upload all files and folders.
3. Go to repository Settings → Pages.
4. Select the main branch and root folder.
5. Save and open the generated GitHub Pages URL.
