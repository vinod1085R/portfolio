# Vinod R — Portfolio

Personal portfolio for Vinod R, a third-year BCA student exploring **Full Stack Development and Cybersecurity**.

## Built with
- HTML5 for page structure
- CSS3 for responsive layouts, themes, cards, and animations
- Vanilla JavaScript for day/night mode, navigation, certificate previews, and contact email

## Run locally
1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` with the VS Code **Live Server** extension, or open it directly in a browser.

## Main sections
- Profile and education
- Technical skills and learning interests
- Circlo logo and full-height app screenshots
- Cybersecurity learning path
- Certificates with a click-to-view modal
- Achievements, GitHub, LinkedIn, and contact details

## Project status and accuracy
Circlo is shown as in development. The cybersecurity section is explicitly presented as a learning path, not professional experience. Update the project status and links when the actual repositories or live demos are ready.

## Publish using GitHub Pages
1. Push the complete folder contents to the intended GitHub repository.
2. Open repository **Settings → Pages**.
3. Select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save.
4. Wait for the Pages deployment to finish and open the published URL.

## Before applying for jobs
- Replace generic repository links in project cards with the exact repository URL for each project.
- Add a real demo URL only after the project is deployed and working.
- Keep project READMEs updated with features, setup instructions, screenshots, and technologies actually used.
- Add new skills only when you can explain and demonstrate them.
- Add a PDF resume only when it is current and reviewed.
